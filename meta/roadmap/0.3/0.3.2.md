- **The private LLVM must be first on `PATH`**, and `env.sh` puts it there;

  0a, and every `@@RUN_DATE@@` of the three steps becomes that date. Leave the
  file for the whole run; a re-run of `apply.py` under it says `ALREADY`. **No
  file the patches touch holds `@@RUN_DATE@@`** — read at planning — so the
  substitution can change nothing but the patches' own placeholders.
- **Amending a patch**: replay the three raw, re-cut requiring byte-identity,
  amend the one, and cherry-pick the others after it; a conflict marks the
  hunk to re-cut (`0.3.0.md` §6).
- **A check over a copy is not the checkout's check**: it reads its exemptions
  only over its own tree, so `facts.sh` asks each copy's own checks.
- **`git apply` inside this checkout resolves a patch's paths against the
  checkout**, not a copy: `facts.sh` applies with GNU `patch -d`.
- **The mutants' anchors are text**: `swap` counts each, and a mutant that
