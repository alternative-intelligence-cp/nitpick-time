PROBE 11 — the `failsafe` arm contract. THE TRANSCRIPT, VERBATIM.

Every command below was run from the repository root on 2026-09-03 against the
pinned toolchain (compiler commit 950bb1d, LLVM 20.1.2), and EVERY ONE CARRIES
ITS EXIT CODE. That is not decoration: a file that fails to compile stops early
and is the fastest row in any timing table, and this subcycle has twice drawn a
wrong conclusion from a timing with no exit code beside it.

The six files and what each one isolates:

  11d  floor_only            imports nothing, computes nothing   -> compiles, runs, exit 0
  11   failsafe_arms         both support modules, nine arms     -> compiles, runs, exit 0
  11b  arm_omitted_refused   11 minus the `(EProbeZone)` line    -> REACH-002, npkc exit 1
  11c  import_arm_cost       an import that divides and indexes,
                             a floor-only failsafe               -> REACH-002 x4, npkc exit 1
  11e  unused_import_refused imports the raiser, never calls it  -> REACH-002, npkc exit 1
  11f  declared_unraised     imports a DECLARED, never-raised
                             identity, floor-only failsafe       -> compiles, runs, exit 0

11d is the control that makes 11c a measurement: 11c's `failsafe` is 11d's,
character for character, and 11d compiles with it. So the four arms 11c is
asked for are four arms THE IMPORT ADDED.
