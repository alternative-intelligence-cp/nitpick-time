### 1.3 DEF-104 reaches a probe here, and not `src/`

`probe13d`'s accessor is `func:vec_at_unchecked<T> = T(Vec<T>->:v, int64:i)
never fails { pass v.items[i]; };` — `probe13b`'s with the slice line

storage from a frame that never owned it (D-183)"*. That is the compiler's
DEF-104, whose gates ask D-264's predicate of a `T` PLACE read out of a lent
or pointed-to container as well as of a lent `T` parameter. **Measured, the
gate reads the generic body itself**: a generic `get<T>` passing `c.p[0]` out

a library module alone — so compiling `src/lib.npk`, which the harness's
library stage does, checks every generic in `src/core/vec.npk`, and it passes.

lays a `#wild_slice` over the block and passes `s[i]` — a place in a LOCAL
slice, which the gate does not read as a pointed-to container; at an owning
`T` that `pass` moves the element out and vacates its slot, which
`tests/probe/defect/generic_owning_copy/case5_vec_at_destructive.npk` still
asserts at exit 11 at this pin — the language behaving as specified, and the
reason `Vec<T>` is for a non-owning `T` (TM-132, S-18d). `vec_pop<T>` spells
`move(s[v.count - 1i64])`, which the gate admits. (`nitpick-regex`'s planner
read the same file and reached the same answer, and read the slice route, for
a LENT `Vec`, as a move out of the caller's block through the loan — its
`vec_get` takes a `Pod` bound instead. For this repository's pointer parameter
the move is the spelling the language gives (`move(v.items[i])` compiles
through a pointer), and `vec_at` at an owning `T` is 0.1.3c's to settle with
the port; §11.)

```python
            text = fh.read()

    with open(path, "ab") as fh:
        fh.write(text.encode("utf-8"))
    print(text, end="")
    committed = [l for l in old.splitlines() if re.match(r"^\S+\s+c3bdae2\s", l)]
```

```python
#!/usr/bin/env python3
"""0.1.4c step 6: every `.npk` in the tree AFTER the adoption -- the tracked
ones and the new ones not yet added -- rooted at $NPKC from its own directory,
in `facts.py`'s format, saved to $W/sweep_after.txt and compared, file by
file, with step 1's $W/sweep_<PIN>.txt: each file that is new or whose line
changed is printed with both lines, then the counts and the codes."""
import os, re, subprocess

REPO, W, PIN = os.environ["REPO"], os.environ["W"], os.environ["PIN"]
DIAG = re.compile(rb"^(NITPICK-[A-Z]+-\d+) (\S+?):(\d+):(\d+):", re.M)
files = sorted(set(subprocess.run(
    ["git", "-C", REPO, "ls-files", "--cached", "--others", "--exclude-standard", "*.npk"],
    stdout=subprocess.PIPE, text=True, check=True).stdout.split()))


def line(rel):
    d, b = os.path.split(os.path.join(REPO, rel))
    p = subprocess.run([os.environ["NPKC"], b, "-o", "/dev/null"], cwd=d,
                       stdout=subprocess.PIPE, stderr=subprocess.STDOUT)
    seen, got = set(), []
    for m in DIAG.finditer(p.stdout):
        code, path, ln, col = (x.decode() for x in m.groups())
        if code not in seen:
            seen.add(code)
            where = "" if os.path.basename(path) == b else os.path.basename(path) + ":"
            got.append("%s@%s%s:%s" % (code, where, ln, col))
    return "%-62s exit %d %s" % (rel, p.returncode, " ".join(got))


after = {rel: line(rel) for rel in files}
with open(os.path.join(W, "sweep_after.txt"), "w", encoding="utf-8") as fh:
    fh.write("\n".join(after[r] for r in files) + "\n")
before = {}
with open(os.path.join(W, "sweep_%s.txt" % PIN), encoding="utf-8") as fh:
    for l in fh.read().splitlines():
        before[l.split()[0]] = l
new = [r for r in files if r not in before]
gone = [r for r in before if r not in after]
changed = [r for r in files if r in before and before[r].rstrip() != after[r].rstrip()]
print("%d file(s) after, %d before: %d new, %d gone, %d changed, %d the same"
      % (len(after), len(before), len(new), len(gone), len(changed),
         len(after) - len(new) - len(changed)))
def verdict(l):
    """What a line says after its path -- `exit N` and the codes."""
    return "exit " + l.split(" exit ", 1)[1].rstrip()


for r in changed:
    print("  changed %s\n      before %s\n      after  %s" % (r, verdict(before[r]), verdict(after[r])))
for r in new:
    print("  new     %s\n      after  %s" % (r, verdict(after[r])))
for r in gone:
    print("  GONE    %s" % r)
ok = sum(1 for r in files if " exit 0 " in after[r] + " ")
tally = {}
for r in files:
    for c in re.findall(r"NITPICK-[A-Z]+-\d+", after[r]):
        tally[c] = tally.get(c, 0) + 1
print("after: %d compile, %d refused; codes: %s" % (ok, len(files) - ok, "  ".join(
    "%s x%d" % (c[len("NITPICK-"):], n) for c, n in sorted(tally.items()))))
```
