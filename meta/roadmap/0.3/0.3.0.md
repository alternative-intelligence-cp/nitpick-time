| Program, in a consumer | Verdict |

### 1.11 The specifications, read against each other

- **H-1** names `host_clock_res = Duration(HostClock:which)` and no
  specification declares `HostClock`. `InstantClock` cannot serve: it has no
  realtime clock, and **must not gain one** — `instant_of(ns,
  InstantClock.Realtime)` would build an `Instant` from the wall clock under
  the type's own name, M-3's hazard. So `HostClock` is `host`'s own, three
  variants (PD-93).
- **H-1** says the module contains *"exactly five public functions and nothing
  else"*. At 0.3.0 it holds four of the five, `HostClock`, five private
  `fixed` numbers and one private helper, `timespec_ns` — PD-93 dates H-1 to
  say what "nothing else" covers: no sixth PUBLIC function.
- **`SAFETY.md` S-8** lists `host_clock_resolution(which)`; every other site
  says `host_clock_res`. H-1 is the module's specification.
- **H-4's** `CLOCK_MONOTONIC` row, *"(not used — see H-5)"*: no reading uses
  it; `host_clock_res` does.
- **B-17** draws `host` → `zone`, `cal`, `core`, and `checks.HOST_MAY_IMPORT`
  is that set (§1.6).

def _literal_width(tok):
    """A numeric literal's width suffix as the lexer's `strip_type_suffix`
    strips it -- the longest of the thirty-seven `num_width_of` knows, with
    something left before it -- or '' for none."""
    for n in range(6, 1, -1):

#[derive(Eq, Clone, Debug, Copy)]
pub enum:HostClock = { Realtime; Monotonic; Boottime; };

func:timespec_ns = int64(int64:secs, int64:nanos) {
    if (secs < 0i64)                  { fail ETimeValue; }
    if (nanos < 0i64)                 { fail ETimeValue; }
    if (nanos >= NTIME_NANOS_PER_SEC) { fail ETimeValue; }
    int64:top = NTIME_DURATION_NS_MAX / NTIME_NANOS_PER_SEC;
    if (secs > top)                   { fail ETimeValue; }
    if (secs == top) {
        if (nanos > (NTIME_DURATION_NS_MAX % NTIME_NANOS_PER_SEC)) { fail ETimeValue; }
    }
    pass (secs * NTIME_NANOS_PER_SEC) + nanos;
};

pub func:host_now_utc = Timestamp() {
    buffer:ts = buffer_new(16i64);
    Result<int64>:r = sys(SYS_CLOCK_GETTIME, CLOCK_REALTIME, ts.ptr);

    int64:nanos = <-(#ptr_add<int64>(ts.ptr, 1i64));
    pass (relay timestamp_of(secs, nanos));
};

pub func:host_now_instant = Instant() never fails {

};
