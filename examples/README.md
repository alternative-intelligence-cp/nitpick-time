# `examples/`

Runnable demonstrations — cycle 1.0.3's, one per format and one of the
DST-edge resolution modes ([`../meta/roadmap/1.0/README.md`](../meta/roadmap/1.0/README.md)) —
each built **and run** by the harness once it has a stage for this directory,
so a broken example is a red run. Nothing is here yet, and the harness has no
such stage. The dogfood consumers — a `date`-equivalent CLI and a small
scheduler — are cycle 0.7's and live in `nitpick-posix`, not here (TM-103).

*(Until cycle 0.3.3 this read "built and run by the harness" as a fact, which
no stage made one — the documents audit's TA-7 — and "the dogfood consumers
from cycle 0.7 live here too", which TM-103 settled the other way on
2026-09-03 — the early ecosystem audit's E2-6, this repository's part.)*
