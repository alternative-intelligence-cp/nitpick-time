## 1. What was measured — the facts this plan rests on

All at compiler `5fbaf4a`, over the tree 0.2.4a's commit leaves, in scratch
copies under this repository's `.internal/`, each program compiled by the
pinned `npkc` and, where it compiled, run at `-O0` and again after `opt -O2`.
**The worker re-derives each with block 0b** and stops on any difference.

### 1.1 C1 — `timestamp_add` handed a forged `secs`

Forged through `wild` storage, as `tests/unit/timestamp_add_edges.npk` forges,
at `HEAD`: `int64`'s largest `secs` plus a second **exits 93** (the add); the
same `secs` with 999 999 999 nanoseconds plus a nanosecond, 93 (the carry);
`int64`'s smallest less a nanosecond, 93 (the borrow); the three with a zero
`Duration`, refused; `int64`'s largest less 9 223 372 036 seconds plus
`int64`'s largest `Duration`, 93, and less 9 223 372 037, refused; the same at
the bottom. With §4.1's `timestamp_add`, **every one refused**, on both legs.

### 1.2 C6 — `instant_since` handed two readings `instant_of` builds

At `HEAD`: (`int64` max, −1), **93**; (max, 0), answered `int64` max exactly;
(`int64` min, 1), 93; (min + 1, 1), answered `int64` min. With §4.1's, the two
93s are **refused** and the two answers unchanged.

### 1.3 C2 — a consumer builds an `Instant` from a `Timestamp`'s numbers

A consumer of `span`, no `wild`, no `=>!`: a `Timestamp` read, its two fields
multiplied out into `instant_of` with `InstantClock.Monotonic`, five seconds
added and measured by `instant_since`, and the `Instant`'s `ns` divided back
into `timestamp_of` — **exit 0 on both legs**, every number exact. `5i128 =>!
Timestamp` is `NITPICK-TYPE-032`.

### 1.4 K2 — a forged hour of 24

A `CivilTime` forged with hour 24 and the rest zero, beside 2026-10-02 from
`civil_date`, handed to `civil_to_utc`: **answered with 2026-10-03's
midnight**, exit 0 on both legs — misleading and never misbehaving, which
`CALENDAR.md` C-8b allows.

### 1.5 S2 — the statement form of `#unreachable()`

`if (r.is_error) { #unreachable(); }` before a read of `r.value`: **`npkc` exit
1, `NITPICK-TAINT-001`**; `take() ?| #unreachable()`: compiles.

### 1.6 C5 — every contract comment made a live clause

`contracts.py` over `HEAD`: **forty contract comments, thirteen compile** as
live clauses, every one that wrote `answer` refused `NITPICK-RESOLVE-002`; read
with `result` for `answer`, twenty-nine — the eleven that do not are four
`NITPICK-TYPE-007`s (an operand of another width than the field it is compared
with), `vec_truncate`'s `min`, which does not exist (`NITPICK-RESOLVE-002`),
three calls without `raw` (`NITPICK-TYPE-060`), and three `prove`s above a
function, with no statement to become. After step 1 (block 1): **forty-three,
thirty-nine compile**, and the four that do not call a function whose callee is
not `pure` (`NITPICK-TYPE-060`).

### 1.7 §4.1's module

`span.npk` with §4.1's code: **`npkc` exit 0**. `instant_since`'s IR holds one
`llvm.ssub.with.overflow.i128` and no `__*ti3` or `__*ti4` libcall, nor does
the module. A root importing `span` alone owes **11 identities**, and the
umbrella **13** — no new identity, no new arm. `check_int128_sites` over it: a
finding for each `int128` in `instant_since`, until step 3 marks §5's row.

```nitpick
mod:span;

use "../cal/cal.npk".ETimeValue;
use "../cal/cal.npk".CivilDate;
use "../cal/cal.npk".CivilTime;
use "../cal/cal.npk".CivilDateTime;
use "../cal/cal.npk".days_to_date;
use "../cal/cal.npk".date_to_days;
use "../cal/cal.npk".civil_time;
use "../core/limits.npk".NTIME_SECS_MIN;
use "../core/limits.npk".NTIME_SECS_MAX;
use "../core/limits.npk".NTIME_NANOS_PER_SEC;
use "../core/limits.npk".NTIME_SECS_PER_DAY;
use "../core/limits.npk".NTIME_DURATION_NS_MAX;
use "../core/limits.npk".NTIME_DURATION_NS_MIN;

#[derive(Eq, Clone, Debug, Copy)]
pub enum:InstantClock = { Monotonic; Boottime; };

#[derive(Eq, Clone, Debug, Copy)]
pub struct:Instant = { sealed int64:ns; sealed InstantClock:clock; };

// The one constructor, and it checks nothing: a reading's range is its type's,
// any `int64` on either clock, so `VERIFICATION.md` P-3 asks no contract of
// it. A number computed from anything -- a `Timestamp`'s fields included --
// becomes a reading that names, in writing, the clock it claims to have read
// (TM-216; `meta/OPEN_QUESTIONS.md` Q-7 asks whether the name should say
// so).
pub func:instant_of = Instant(int64:ns, InstantClock:clock) never fails {
    pass Instant{ ns: ns, clock: clock };
};

// The span between two readings of one clock. Computed in `int128` (M-20;
// `SPAN_MODEL.md` §5 marks the row), refused past `Duration`'s range rather
// than trapped (`SAFETY.md` S-12), and narrowed once.
pub func:instant_since = Duration(Instant:later, Instant:earlier) {
    if (later.clock != earlier.clock) { fail ETimeValue; }   // ValueFault.ClockMismatch
    int128:ns = (later.ns => int128) - (earlier.ns => int128);
    if (ns > (NTIME_DURATION_NS_MAX => int128)) { fail ETimeValue; }   // ValueFault.Overflow
    if (ns < (NTIME_DURATION_NS_MIN => int128)) { fail ETimeValue; }   // ValueFault.Overflow
    // `prove(ns >= (NTIME_DURATION_NS_MIN => int128)
    //        && ns <= (NTIME_DURATION_NS_MAX => int128));` -- P-5
    pass raw duration_ns(ns =>! int64);
};

pub func:instant_add = Instant(Instant:t, Duration:d) never fails {
    pass Instant{ ns: t.ns + d.ns, clock: t.clock };
};

pub func:instant_cmp = Ordering(Instant:a, Instant:b) {
    if (a.clock != b.clock) { fail ETimeValue; }              // ValueFault.ClockMismatch
    if (a.ns < b.ns) { pass Ordering.Less; }
    if (a.ns > b.ns) { pass Ordering.Greater; }
    pass Ordering.Equal;
};

#[derive(Eq, Ord, Clone, Debug, Copy)]
pub struct:Timestamp = { sealed int64:secs; sealed uint32:nanos; };

// `ensures result.secs == secs && (result.nanos => int64) == nanos` --
// `VERIFICATION.md` P-3; and P-4, the invariant to prove first, is the `prove`
// before the narrowing. Comments until the verified build (P-1b), and stood in
// for by `tests/unit/timestamp_construct.npk`.
pub func:timestamp_of = Timestamp(int64:secs, int64:nanos) {
    if (secs < NTIME_SECS_MIN)        { fail ETimeValue; }   // ValueFault.YearRange
    if (secs > NTIME_SECS_MAX)        { fail ETimeValue; }   // ValueFault.YearRange
    if (nanos < 0i64)                 { fail ETimeValue; }   // ValueFault.NanoRange
    if (nanos >= NTIME_NANOS_PER_SEC) { fail ETimeValue; }   // ValueFault.NanoRange
    // `prove(nanos >= 0i64 && nanos < NTIME_NANOS_PER_SEC);` -- P-4
    pass Timestamp{ secs: secs, nanos: nanos =>! uint32 };
};

// The civil reading, in UTC, of a point on the absolute scale (M-11, §9).
// `never fails`: a `Timestamp` is in the range and normalised by construction,
// so neither refusal below can happen to one, and each is S-15c's stop.
pub func:timestamp_to_utc = CivilDateTime(Timestamp:t) never fails {
    int64:days = t.secs / NTIME_SECS_PER_DAY;
    int64:sod = t.secs % NTIME_SECS_PER_DAY;
    if (sod < 0i64) {                                // `/` truncates: floor it
        days = days - 1i64;
        sod = sod + NTIME_SECS_PER_DAY;
    }
    CivilDate:d = days_to_date(days) ?| #unreachable();             // M-8
    CivilTime:c = civil_time(sod / 3600i64, (sod / 60i64) % 60i64, sod % 60i64,
                             t.nanos => int64) ?| #unreachable();   // M-7
    pass CivilDateTime{ date: d, time: c };
};

// The point on the absolute scale a civil reading names, read as UTC (M-11,
// §9). Fallible, and only through `timestamp_of`: a reading from the
// constructors always converts, and a forged one is refused, not trapped.
// `ensures result.secs >= NTIME_SECS_MIN && result.secs <= NTIME_SECS_MAX`
// `ensures (result.nanos => int64) == (c.time.nanos => int64)` --
// `VERIFICATION.md` P-3, a `Timestamp` constructor's; comments until
// the verified build (P-1b), and stood in for by
// `tests/unit/civil_to_utc_edges.npk`.
pub func:civil_to_utc = Timestamp(CivilDateTime:c) {
    int64:days = raw date_to_days(c.date);
    int64:sod = ((c.time.hour => int64) * 3600i64)
                + ((c.time.minute => int64) * 60i64) + (c.time.second => int64);
    pass (relay timestamp_of((days * NTIME_SECS_PER_DAY) + sod,
                             c.time.nanos => int64));
};

// `ntime`'s four constructors (`SPAN_MODEL.md` N-2): each multiplies in `int64`
// and hands the seconds to the prelude's `duration_secs`, whose own `* 10^9`
// traps past `Duration`'s range -- the range check, so each is `never fails`.
// A day is exactly 86 400 x 10^9 nanoseconds, and not a calendar day.
pub func:duration_mins = Duration(int64:m) never fails {
    pass raw duration_secs(m * 60i64);
};

pub func:duration_hours = Duration(int64:h) never fails {
    pass raw duration_secs(h * 3600i64);
};

pub func:duration_days = Duration(int64:d) never fails {
    pass raw duration_secs(d * NTIME_SECS_PER_DAY);
};

pub func:duration_weeks = Duration(int64:w) never fails {
    pass raw duration_secs(w * 7i64 * NTIME_SECS_PER_DAY);
};

// The point `d` from `t` (§9). `t`'s seconds are checked against the range
// first (`SAFETY.md` S-12), so nothing below can trap whatever `t` holds;
// then `/` and `%` truncate, so the remainder keeps `d`'s sign and the
// nanoseconds come out in (-10^9, 2 x 10^9) -- at most 2^32 - 1 + 10^9 for a
// forged `nanos` -- and one borrow or one carry puts a normalised one back in
// [0, 10^9), and `timestamp_of` builds the answer, refusing what one carry
// cannot repair.
// `ensures result.secs >= NTIME_SECS_MIN && result.secs <= NTIME_SECS_MAX`
// `ensures (result.nanos => int64) < NTIME_NANOS_PER_SEC` -- `VERIFICATION.md`
// P-3; comments until the verified build (P-1b), and stood in for by
// `tests/unit/timestamp_add_edges.npk`.
pub func:timestamp_add = Timestamp(Timestamp:t, Duration:d) {
    if (t.secs < NTIME_SECS_MIN) { fail ETimeValue; }    // ValueFault.YearRange
    if (t.secs > NTIME_SECS_MAX) { fail ETimeValue; }    // ValueFault.YearRange
    int64:secs = t.secs + (d.ns / NTIME_NANOS_PER_SEC);
    int64:nanos = (t.nanos => int64) + (d.ns % NTIME_NANOS_PER_SEC);
    if (nanos < 0i64) {                              // `%` kept `d`'s sign: borrow
        secs = secs - 1i64;
        nanos = nanos + NTIME_NANOS_PER_SEC;
    }
    if (nanos >= NTIME_NANOS_PER_SEC) {              // past a second: carry
        secs = secs + 1i64;
        nanos = nanos - NTIME_NANOS_PER_SEC;
    }
    pass (relay timestamp_of(secs, nanos));          // ValueFault.YearRange outside
};

// The nominal span from `earlier` to `later`, in nanoseconds (M-18). Computed
// in `int128` (M-20; `SPAN_MODEL.md` §5 marks the row), checked against
// `Duration`'s range, and narrowed once, after P-5's `prove`; a comment until
// the verified build (P-1b).
pub func:timestamp_since = Duration(Timestamp:later, Timestamp:earlier) {
    int128:ns = (((later.secs => int128) - (earlier.secs => int128))
                 * (NTIME_NANOS_PER_SEC => int128))
                + ((later.nanos => int128) - (earlier.nanos => int128));
    if (ns > (NTIME_DURATION_NS_MAX => int128)) { fail ETimeValue; }   // Overflow
    if (ns < (NTIME_DURATION_NS_MIN => int128)) { fail ETimeValue; }   // Overflow
    // `prove(ns >= (NTIME_DURATION_NS_MIN => int128)
    //        && ns <= (NTIME_DURATION_NS_MAX => int128));` -- P-5
    pass raw duration_ns(ns =>! int64);
};
```
