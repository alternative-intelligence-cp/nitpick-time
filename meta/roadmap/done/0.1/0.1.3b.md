**What that overturns, and what it does not.**

- **A table may hold an owner** — every pin. The premise's first sentence is
  false, and was false for as long as this repository has had a pin.
- **A copy out is refused** (`probe17b`, `probe17c`: `NITPICK-TYPE-046`) —
  every pin. **This is the fact the rule now stands on**: `SAFETY.md` S-17 reads
  every zone table through one accessor pair, which returns a row BY VALUE, and
  a row that owns cannot be returned by value.
- **A move out compiles and faults** — every pin. `fixed` storage is an LLVM
  `constant` global; moving an element out stores the vacancy into it, which is
  undefined behaviour: SIGSEGV at -O0 (139; `MachineFault`, 107, at `c3bdae2`,
  whose runtime handles the signal; `Unreachable` at `950bb1d`), and under
  `opt -O2` the store is deleted and the moved string's drop frees read-only
  bytes (`Unreachable`, 95). A scalar writes no vacancy and stops at 95 on
  both legs. **The premise's last clause — "nothing may move out of" — is the
  compiler's defect described as though it were the language's rule.** The
  control (`case4`, the same reads by `.clone()`) is clean everywhere, so it is
  the move that faults.
- **A `wild` pointer does not make a struct owning** — the old comment listed
  it and the code never looked for it; a whole-`Vec` copy compiles (question 9,
  measured at cycle 0.1.0c).

**And three blind spots in the check itself**, found by re-reading it against
those facts rather than by any failure:

1. **An owning ELEMENT is invisible**: the check looks up the element type's
   struct fields, and `string` has none — so `fixed string[2]:NAMES`, the table
   `probe17c` declares, reports clean.
2. **An owner two structs down is invisible**: `Row { int64; Name }` with
   `Name { string }` — the check reads `Row`'s fields and stops.
3. **Owners are matched by substring**: a field named `string_off` reads as a
   `string`, so the check is also capable of the opposite error.

Each is planted in §4 and seen red against the check as it stands before the
check changes.

## 2. The design

- **The rule stays, on a reason that holds** (PD-28): no `fixed` table holds an
  owning value — as its element or as a field of its element at any depth —
  because a copy out is refused and a move out faults. `SAFETY.md` gains
  **S-19b** with the measurement table; §1's row, `TESTING.md` §2's row and
  `CLAUDE.md`'s line are restated, each keeping its old words quoted.
- **The check sees what the rule says** (PD-28): an owning element; an owner at
  any depth; a field's TYPE, not its name. Commissioned first (TM-126): two new
  plants, red against the old check — three problems, measured — and silent
  after.
- **The evidence is committed**: `probe17` (the reads that work, both legs),
  `probe17b` and `probe17c` (the copies refused), and
  `tests/probe/defect/fixed_move_out/` — three reproductions and the control
  that makes them one, a README, and the generated transcript.
- **The reproductions carry no expectation of their fault** — asserting a
  fault as a committed expectation is what `generic_owning_copy/case4` refused
  to do with its use-after-free — so each is in `EXPECT_EXEMPT` at its `-O0`
  verdict, re-derived every run (TM-137), and **moves** the day the compiler
  refuses the move.
- **Cycle 0.5's version string is held behind the defect** (PD-29): Z-4's `pub
  fixed string:TZDB_VERSION` and Z-6's `ntime_tzdb_version()` are exactly case

# `fixed_move_out` — a move out of `fixed` storage compiles, and faults

**Raised by path at cycle 0.1.3b, 2026-09-25, and unnumbered here**: `O-N` is
the workbench registry's namespace, and the orchestrator assigns the id when it
registers the question (`PLAYBOOK.md`'s rule, since a worker cannot see what
the registry has issued).

## The defect

**A `move` out of an element, a row's field or a scalar of `fixed` storage
holding an owning value compiles at every pin this repository has kept — and
the program faults.** `fixed` storage is emitted as an LLVM `constant` global.
For an element or a field, the move then stores the vacancy —
`zeroinitializer` — into that constant, which is undefined behaviour in LLVM
IR: at -O0 the store hits read-only memory and the process takes SIGSEGV,
which `c3bdae2`'s runtime turns into `MachineFault`; under `opt -O2` the store
is deleted, as UB may be, the program runs on, and the moved string is later
dropped, freeing bytes the allocator never handed out, which it stops as
`Unreachable`. For a scalar no vacancy is written at all, so a second move
would be a second owner, and the first drop stops the same way.

**A plain `pass` is a move** — `pass NAMES[i]` from a function returning
`string` moves the element implicitly, the language behaving as specified
(`SAFETY.md` S-18d is the same fact for `vec_at<T>`) — so the shape that
reaches this defect need not say "move" anywhere.

What the language DOES refuse is the copy: `NITPICK-TYPE-046` on a by-value
read of an owning row or element (`../../probe17b_fixed_row_copy_refused.npk`,
`../../probe17c_fixed_string_copy_refused.npk`). **The fix this asks for is
the same kind of refusal for the move**: a `fixed` binding is immutable, and
moving out of it writes it.

def _field_type(ftext):
    """A field's type: the last token before its `:`, so that `sealed`,
    `hidden`, `wild` and `limit<R>` are skipped as the qualifiers they are."""
    head = ftext.split(":", 1)[0].split()
    return head[-1] if head else ""


def _owners(structs, name, seen=()):
    """The fields of struct `name` that own, AT ANY DEPTH: a list of
    `(rel, lineno, field_text, via)`, where `via` names the struct a nested
    owner was found through and is None for a field that owns itself."""
    out = []

        if _owning_type(ftype):

        elif ftype in structs and ftype != name and ftype not in seen:
            if _owners(structs, ftype, seen + (name,)):

    return out

```python
#!/usr/bin/env python3
"""0.1.3 and 0.1.3b (`0.1.3.md` §9 step 7, `0.1.3b.md` §7): draft labels become
the next TM numbers, in order, everywhere OUTSIDE the two plan files and
`meta/DECISIONS.md` -- whose new section keeps each label as provenance, as
TM-165 ... TM-168 keep PD-16 ... PD-19.

    renumber.py FIRST_TM [FIRST_PD [COUNT]]      defaults: PD-20, eight labels

FIRST_TM is read by the plan's gate. Tracked AND untracked files (new tests
carry labels, and `git grep` skips untracked files unless told). Exact labels
only: 0.1.0b's own draft label shares a prefix with these, and a pattern that
matched it would renumber history. Prints every file it changed and the count;
exit 1 if a label is left or a heading is missing."""
import os, re, subprocess, sys

REPO = os.environ["REPO"]
first = int(sys.argv[1])
pd0 = int(sys.argv[2]) if len(sys.argv) > 2 else 20
count = int(sys.argv[3]) if len(sys.argv) > 3 else 8
MAP = {"PD-%d" % (pd0 + i): "TM-%d" % (first + i) for i in range(count)}
LABEL = re.compile(r"\b(?:%s)\b" % "|".join(re.escape(k) for k in MAP))
PATTERN = "|".join(r"PD-%d\b" % (pd0 + i) for i in range(count))
KEEP = {"meta/roadmap/0.1/0.1.3.md", "meta/roadmap/0.1/0.1.3b.md", "meta/DECISIONS.md"}
files = subprocess.run(["git", "-C", REPO, "grep", "-l", "--untracked", "-E", PATTERN],
                       stdout=subprocess.PIPE, text=True).stdout.split()
changed = 0
for rel in files:
    if rel in KEEP:
        continue
    path = os.path.join(REPO, rel)
    text = open(path, encoding="utf-8").read()
    new, n = LABEL.subn(lambda m: MAP[m.group(0)], text)
    open(path, "w", encoding="utf-8").write(new)
    changed += n
    print("  %-44s %d label(s)" % (rel, n))
dec = open(os.path.join(REPO, "meta/DECISIONS.md"), encoding="utf-8").read()
missing = [t for t in MAP.values() if not re.search(r"^### %s\b" % t, dec, re.M)]
left = subprocess.run(["git", "-C", REPO, "grep", "-l", "--untracked", "-E", PATTERN],
                      stdout=subprocess.PIPE, text=True).stdout.split()
left = [r for r in left if r not in KEEP]
print("labels renumbered: %d; PD-%d -> %s" % (changed, pd0, MAP["PD-%d" % pd0]))
if missing:
    print("  STOP: meta/DECISIONS.md declares none of: %s" % ", ".join(missing))
if left:
    print("  STOP: labels left in: %s" % ", ".join(left))
sys.exit(1 if missing or left else 0)
```
