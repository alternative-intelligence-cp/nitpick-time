### 1.2 The language at the pin

- **Fifty-seven bare-name builtins** — `is_builtin_name` in

## 4. The code

### 4.1 `harness/checks.py` — the emission's reader and its two checks (PD-95, PD-96)

After `check_host_isolation`, three sections:

- **The reader.** `EMISSION = "build/ntime.ll"`. `read_emission(path)` returns
  `{name: body}` for each `define` (the text to the `}` that ends it), the set
  of `declare`d names, and `{name: initializer}` for each global; `None` for no
  file. `_ir_module` reads `npk.<module>.`; `_src_modules(tree)` gives the
  basenames of `src/`'s files and of `src/host/`'s; `_ir_source_name` strips
  `npk.<module>.` and a generic's `<…>`. Two patterns name the calls a reading
  of names cannot follow: `_IR_INDIRECT`, a callee `%value(`, and `_IR_ASM`,
  `call … asm …"` — each after `call`, `invoke` or `callbr`, every instruction
  that calls, though `npkc` emits only `call` at the pin.
- **`check_call_edges(tree, emission=None)`.** `CALL_EDGE_ALLOW` — twenty
  rows, each a runtime symbol with its class: the allocator (`npk_alloc`,
  `npk_aalloc`, `npk_calloc`, `npk_ralloc`, `npk_dalloc`, `npk_alloc_managed`,
  `npk_buffer_new`, `memcpy`, `memmove`, `memset`), the string floor
  (`npk_string_concat`, `npk_int_to_string`, `npk_string_slice`,
  `npk_string_equals`, `npk_string_from_bytes`, `npk_to_cstring`) and the
  error route (`npk_trap`, `npk_raise`, `npk_chain_push`, `npk_chain_reset`);
  and `CALL_EDGE_INTRINSICS`, three families — the overflow intrinsics,
  `llvm.assume`, `llvm.sqrt.f32`/`f64`. `_reach(start, …)` walks breadth
  first, so each finding names the shortest path; it stops at a function of
  `src/`. The findings, in order: a symbol outside the allowlist; a function of
  `src/host/`; a call through a value or inline assembly, in the start or a
  body it passes through; the positive control; a stale row; a non-generic
  function `src/` declares and the emission lacks (`_declared_functions`,
  which reads a `func:name<` as generic). The headline, at the pin: *"90
  function(s) of src/'s modules in the emission, 81 outside src/host/,
  reaching 15 runtime symbol(s), 0 outside the reviewed allowlist; src/host/
  reaches npk_mono_now, npk_sys6; 48 of 48 non-generic function(s) src/
  declares in it, 9 generic read by spelling alone"*.
- **`check_wide_types(tree, emission=None)`.** `_IR_WIDE` reads `iN` with no
  name character, `.`, `%`, `@`, `$` or quote before it — so an intrinsic's
  `.i256` suffix and a value named `%i128` are not types, and a generic's
  `<int128>` is no `iN` at all — and `_ir_widths` keeps widths past 64. A
  function holding one whose source name §5 does not mark is a finding; a
  global of `src/`'s modules holding one is a finding. The headline: *"3 of
  90 function(s) of src/'s modules in the emission hold an integer wider than
  i64 (bytes_put_int, instant_since, timestamp_since); 4 site(s) §5 marks, 1
  not in the emission (period_add)"*.

## 6. What will bite

- **A check is called by its name in `run.py`**, never through a loop or a
  variable: `check_check_registry` reads the names `run.py` calls (§4.2).
- **The two new checks read `build/ntime.ll`**, which step 7 writes — over the
  checkout after a full run, over a copy after `emit`. A `check` call before
  either reads a stale emission or none, and says so (`_no_emission`).
- **Steps 1 and 2 are STAGED, not committed**, each later patch cut from the
  tree the earlier one leaves; step 1 is committed before step 2 applies.
- **The run is dated once**: `env.sh` writes `.internal/w031/run_date` at block
  0a, and every `@@DATE@@` of both steps becomes that date. Leave the file for
  the whole run; a re-run of `apply.py` under it says `ALREADY`.
- **Amending a patch**: replay both raw, re-cut requiring byte-identity, amend
  the one, and cherry-pick the other after it; a conflict marks the hunk to
  re-cut (`0.3.0.md` §6).
- **A check over a copy is not the checkout's check**: it reads its exemptions
  only over its own tree, so `facts.sh` asks each copy's own harness.
- **`git apply` inside this checkout resolves a patch's paths against the
  checkout**, not a copy: `facts.sh` applies with GNU `patch -d`.
- **The mutants' anchors are text**: `swap` counts each, and a mutant that
  matches nothing or twice is a STOP and not the mutant named. An anchor
  holding a regex's `\n` would be read as a newline, so the two regex mutants
  anchor on `re.compile(_IR_CALL + r'`.
- **A red-first prediction covers the controls**: block 2's six problems are
  five unseen plants and one control fired.
- **The plant count is written in words and in digits** — *"one hundred and
  twelve"*, `112` — in `CLAUDE.md`, `harness/README.md` and the cost table:
  sweep both.
- **The cycle README's plants are a copy's, never the tree's** — and never a
  self-check row over the real file (§4.3).
- **No Expect names a decision that does not exist yet**, and no fence here
  quotes a comment that does.
