### 1.2 The inherited item — a literal widens unnamed

| Program, in a consumer | Verdict |
|---|---|
| `int64:y = (3i256 * 5i256) =>! int64;`, and `(10000000000i256 * 10000000000i256) =>! int64` held to `7766279631452241920i64` | **`npkc` 0, exit 0 on both legs** — 10²⁰ narrowed to its low 64 bits, a constant wrong in silence |
| `int64:x = argv.len; (x * 5i256) =>! int64` | **`NITPICK-TYPE-007`** — *"`int64` and `int256` are different types; write the cast you mean; a widening would decide which width this operation happens in, and that decision must be visible in the source"* |
| `((x => int256) * 5i256) =>! int64` | `npkc` 0, exit 0 on both legs — the type is named, and the check reads it |

So **a runtime value cannot widen without naming the type** — the compiler's
own rule — and the gap is a computation of literals alone. Planted in a copy's
`src/span/span.npk` as a function §5 marks no row for, `pass (3i256 * 5i256)
=>! int64;` compiles in `span` and **`check_int128_sites` reports 0 findings**
(its headline `14 … in 3 function(s)`, as the tree's); the same function
spelling `(3i64 => int256)` is 1 finding. `src/`'s 235 numeric literals hold
one wide width suffix, `0i128`, in `bytes_put_int`'s loop measure — a function
§5 marks, beside its `(x => int128)`.

**The fix, prototyped in a copy** (§4.1): the check reads `checks.literals`
for each file and takes a literal whose width suffix is one of the fourteen

## 2. The decisions, and what chose each

| Label | Decision | Why this and not the alternative |
|---|---|---|
| **PD-91** | **`check_int128_sites` reads a numeric literal's width suffix as it reads a type's name**: a literal whose suffix is one of the fourteen wide widths — `i128` … `i4096`, `u128` … `u4096`, `tbb128`, `tbb256` — counts as a site of the function it stands in, so outside every function §5 marks it is a finding, and inside one it keeps the mark live. `TESTING.md` §2's row restated (its *"Comments and literals are blanked first"*: comments, strings and characters are; a numeric literal is read for its width); `SPAN_MODEL.md` N-20 dated; TM-240 marked. Two self-check plants: `(3i256 * 5i256) =>! int64` in a function §5 does not mark, beside the same function marked; and `7u128` at module level, beside `7i64`. **The inherited item** (§1.2) | **V-1's claim is every wide intermediate**, and the language lets exactly one kind be written without its type's name; reading the width costs a few lines over `checks.literals`, the reader `check_constants_named` already trusts (TM-231), and moves nothing in the tree. Declined: **V-1 narrowed to intermediates whose type is named** — a check narrower than its rule's reason, the shape this repository keeps finding; **the IR's wide arithmetic read instead** — every `i256` operation the emission holds, but a claim about the lowering and the optimiser, which may fold a literal product away; **every wide literal a finding** — `bytes_put_int`'s `0i128` is a marked site's correct literal |

```nitpick

fixed int64:SYS_CLOCK_GETRES  = 229i64;
fixed int64:CLOCK_REALTIME    = 0i64;
fixed int64:CLOCK_MONOTONIC   = 1i64;
fixed int64:CLOCK_BOOTTIME    = 7i64;

#[derive(Eq, Clone, Debug, Copy)]
pub enum:HostClock = { Realtime; Monotonic; Boottime; };

func:timespec_ns = int64(int64:secs, int64:nanos) {
    if (secs < 0i64)                  { fail ETimeValue; }
    if (nanos < 0i64)                 { fail ETimeValue; }
    if (nanos >= NTIME_NANOS_PER_SEC) { fail ETimeValue; }
    int64:top = NTIME_DURATION_NS_MAX / NTIME_NANOS_PER_SEC;
    if (secs > top)                   { fail ETimeValue; }
    if (secs == top) {
        if (nanos > (NTIME_DURATION_NS_MAX % NTIME_NANOS_PER_SEC)) { fail ETimeValue; }
    }
    pass (secs * NTIME_NANOS_PER_SEC) + nanos;
};

pub func:host_now_utc = Timestamp() {
    buffer:ts = buffer_new(16i64);
    Result<int64>:r = sys(SYS_CLOCK_GETTIME, CLOCK_REALTIME, ts.ptr);
    if (r.is_error) { fail r.err; }
    int64:secs = <-(#ptr_add<int64>(ts.ptr, 0i64));
    int64:nanos = <-(#ptr_add<int64>(ts.ptr, 1i64));
    pass (relay timestamp_of(secs, nanos));
};

pub func:host_now_instant = Instant() never fails {
    pass raw instant_of(mono_now(), InstantClock.Monotonic);
};

pub func:host_now_boot = Instant() {
    buffer:ts = buffer_new(16i64);
    Result<int64>:r = sys(SYS_CLOCK_GETTIME, CLOCK_BOOTTIME, ts.ptr);
    if (r.is_error) { fail r.err; }
    int64:secs = <-(#ptr_add<int64>(ts.ptr, 0i64));
    int64:nanos = <-(#ptr_add<int64>(ts.ptr, 1i64));
    int64:ns = relay timespec_ns(secs, nanos);
    pass raw instant_of(ns, InstantClock.Boottime);
};

pub func:host_clock_res = Duration(HostClock:which) {
    int64:id = CLOCK_REALTIME;
    pick (which) {
        (HostClock.Realtime)  { id = CLOCK_REALTIME; },
        (HostClock.Monotonic) { id = CLOCK_MONOTONIC; },
        (HostClock.Boottime)  { id = CLOCK_BOOTTIME; }
    }
    buffer:ts = buffer_new(16i64);
    Result<int64>:r = sys(SYS_CLOCK_GETRES, id, ts.ptr);
    if (r.is_error) { fail r.err; }
    int64:secs = <-(#ptr_add<int64>(ts.ptr, 0i64));
    int64:nanos = <-(#ptr_add<int64>(ts.ptr, 1i64));
    int64:ns = relay timespec_ns(secs, nanos);

};
```
