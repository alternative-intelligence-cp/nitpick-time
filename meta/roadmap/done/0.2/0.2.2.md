### 1.3 The floor, and what a truncation does

`m_chain` — `tests/unit/timestamp_order.npk`'s eight values, −1.000000001 s … 1 s,
through `timestamp_to_utc` to their civil readings and back through
`civil_to_utc`: **exit 0 on both legs**. Against the module with the floor's
correction deleted — the truncation — **exit 95**, `Unreachable`, on both legs:
`-2 s` truncates to day 0 and a second of −2, `civil_time` refuses it, and the
refusal reaches `#unreachable()`. And `m_first` — every day's FIRST instant in
the range, `n × 86 400`, through `timestamp_to_utc`, its date held to
`days_to_date(n)`: **exit 0 on both legs with the truncation too**. A whole
number of days is where truncating and flooring agree, so first instants alone
cannot see it — which is why the boundary member takes each boundary from both
sides (PD-69).

### 1.4 What the arithmetic can and cannot reach

`civil_to_utc` adds `date_to_days(c.date) × 86 400` to the second of the day.
`date_to_days` is total over every `int32` year and every pair of `uint8`s, at
most 7.84 × 10¹¹ in magnitude (`CALENDAR.md` C-12, asserted by
`tests/unit/civil_total_edges.npk`); times 86 400 that is 6.8 × 10¹⁶, and the
second of the day from three `uint8`s is at most 933 555 — all far inside
`int64`. So no field value traps on the way to `timestamp_of`, whose checks then
decide: the function is total, a refusal or an answer for every field value
(C-8b's second bullet).

### 1.5 The forge, and a forged `Timestamp`

`#size_of` of `CivilDate`, `CivilTime` and `CivilDateTime`: **8, 8 and 16**, as
exit codes on both legs. `m_forge` writes an unsealed struct of `CivilDate`'s
fields — year 10 000 — and one of `CivilTime`'s — 23:59:59 and a `nanos` of one
second — through `wild` pointers, reads each back through the sealed type, field
for field, and hands them to `civil_to_utc`, alone and beside 9999-12-31 from
`civil_date`: **exit 0 on both legs** — each read back exactly, each pair
refused, nothing trapped. `m_forged_ts` forges a `Timestamp` one second past the
range the same way and hands it to `timestamp_to_utc`: **exit 95**, the stop
PD-67 says it is. No `#wild_slice` is written: the forge is a typed pointer.

```nitpick
mod:span;

use "../cal/cal.npk".ETimeValue;
use "../cal/cal.npk".CivilDate;
use "../cal/cal.npk".CivilTime;
use "../cal/cal.npk".CivilDateTime;
use "../cal/cal.npk".days_to_date;
use "../cal/cal.npk".date_to_days;
use "../cal/cal.npk".civil_time;
use "../core/limits.npk".NTIME_SECS_MIN;
use "../core/limits.npk".NTIME_SECS_MAX;
use "../core/limits.npk".NTIME_NANOS_PER_SEC;
use "../core/limits.npk".NTIME_SECS_PER_DAY;

#[derive(Eq, Clone, Debug, Copy)]
pub enum:InstantClock = { Monotonic; Boottime; };

#[derive(Eq, Clone, Debug, Copy)]
pub struct:Instant = { sealed int64:ns; sealed InstantClock:clock; };

pub func:instant_of = Instant(int64:ns, InstantClock:clock) never fails {
    pass Instant{ ns: ns, clock: clock };
};

pub func:instant_since = Duration(Instant:later, Instant:earlier) {
    if (later.clock != earlier.clock) { fail ETimeValue; }   // ValueFault.ClockMismatch
    pass raw duration_ns(later.ns - earlier.ns);
};

pub func:instant_add = Instant(Instant:t, Duration:d) never fails {
    pass Instant{ ns: t.ns + d.ns, clock: t.clock };
};

pub func:instant_cmp = Ordering(Instant:a, Instant:b) {
    if (a.clock != b.clock) { fail ETimeValue; }              // ValueFault.ClockMismatch
    if (a.ns < b.ns) { pass Ordering.Less; }
    if (a.ns > b.ns) { pass Ordering.Greater; }
    pass Ordering.Equal;
};

#[derive(Eq, Ord, Clone, Debug, Copy)]
pub struct:Timestamp = { sealed int64:secs; sealed uint32:nanos; };

// `ensures answer.secs == secs && (answer.nanos => int64) == nanos`
// `prove((answer.nanos => int64) < NTIME_NANOS_PER_SEC)` -- `VERIFICATION.md`
// P-4, the invariant to prove first; a comment until the verified build (P-1b),
// and stood in for by `tests/unit/timestamp_construct.npk`.
pub func:timestamp_of = Timestamp(int64:secs, int64:nanos) {
    if (secs < NTIME_SECS_MIN)        { fail ETimeValue; }   // ValueFault.YearRange
    if (secs > NTIME_SECS_MAX)        { fail ETimeValue; }   // ValueFault.YearRange
    if (nanos < 0i64)                 { fail ETimeValue; }   // ValueFault.NanoRange
    if (nanos >= NTIME_NANOS_PER_SEC) { fail ETimeValue; }   // ValueFault.NanoRange
    pass Timestamp{ secs: secs, nanos: nanos =>! uint32 };
};

// The civil reading, in UTC, of a point on the absolute scale (M-11, §9).
// `never fails`: a `Timestamp` is in the range and normalised by construction,
// so neither refusal below can happen to one, and each is S-15c's stop.
pub func:timestamp_to_utc = CivilDateTime(Timestamp:t) never fails {
    int64:days = t.secs / NTIME_SECS_PER_DAY;
    int64:sod = t.secs % NTIME_SECS_PER_DAY;
    if (sod < 0i64) {                                // `/` truncates: floor it
        days = days - 1i64;
        sod = sod + NTIME_SECS_PER_DAY;
    }
    CivilDate:d = days_to_date(days) ?| #unreachable();             // M-8
    CivilTime:c = civil_time(sod / 3600i64, (sod / 60i64) % 60i64, sod % 60i64,
                             t.nanos => int64) ?| #unreachable();   // M-7
    pass CivilDateTime{ date: d, time: c };
};

// The point on the absolute scale a civil reading names, read as UTC (M-11,
// §9). Fallible, and only through `timestamp_of`: a reading from the
// constructors always converts, and a forged one is refused, not trapped.
pub func:civil_to_utc = Timestamp(CivilDateTime:c) {
    int64:days = raw date_to_days(c.date);
    int64:sod = ((c.time.hour => int64) * 3600i64)
                + ((c.time.minute => int64) * 60i64) + (c.time.second => int64);
    pass (relay timestamp_of((days * NTIME_SECS_PER_DAY) + sod,
                             c.time.nanos => int64));
};
```
