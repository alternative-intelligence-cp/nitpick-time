## 3. The cycle's findings — the numbered list step 3 asks for

Everything cycle 0.0 found that was not a probe verdict or a measurement. The
decisions carry the full arguments; this is the index.

1. **Separate compilation does not exist** (TM-117). Two `npkc` objects are a
   duplicate-symbol error, because every compile emits the whole reachable
   graph including the prelude. The plan said "compile the library once, link
   each program against it" and that is not executable.
2. **An import's arm bill is its `fail` sites PLUS its arithmetic**, charged
   per module (TM-107). Importing a module that declares no error at all costs
   four arms. Avoiding a failing *function* buys nothing.
3. **There is no checked narrowing** (TM-105). `=>!` truncates in silence and
   the checked `=>` at the same narrowing is refused. Every narrowing carries
   its own range check, written by hand.
4. **`exit 0` says nothing about managed memory** (TM-106). D-151 watches
   `wild` allocations only.
5. **`npkc` exit 0 is not well-formedness** (TM-112). Pair every status with
   the artefact it should have produced.
6. **`ulimit -v` sized low measures the loader, not the library** (TM-131).
   `/bin/true` flips at the same cap. Take any address-space bound with a
   `/bin/true` control at the same cap.
7. **Ten `VerificationKeyword` spellings are reserved** (TM-130), including
   `result` and `old`, which this library's own contract syntax uses. And
   `stack`, which is on no list here and reads as a brace imbalance dozens of
   lines away.
8. **A check whose NAME describes a property while its MECHANISM covers
   something narrower is this repository's characteristic defect.** Five
   instances in one cycle: TM-115, TM-137, TM-138, TM-141, TM-144. **Every one
   was found by a reader, none by a run.**
9. **Every gate this repository owns is a LEAK gate** (TM-139). Two
   use-after-frees shipped on the public surface under a green suite. A leak is
   found by a gate; a wrong answer is found by a test that reads.
10. **A derived number in a live document goes stale in silence** (TM-142).
    Eleven sites, six files, three subcycles, every one reachable from the
    runner's own printed output.
11. **A whole-file exemption cannot expire** (TM-145), and it was in the
    mechanism written to prevent exemptions that do not expire.
12. **A specification amended in a roadmap file or a source comment is not
    amended** (TM-143). Four instances, and in every one the correct statement
    already existed somewhere else in the tree.
