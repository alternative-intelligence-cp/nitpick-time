### 1.3 Construction: what `drop` licenses

```text
drop tick(1i64);       tick = NIL(int64:v) never fails        compiles, 0 / 0
tick(1i64);            the same, a bare call                  NITPICK-TYPE-039 "a `Result` is discarded here with no keyword (D-163)"
drop refuse(5i64);     refuse = NIL(int64:v), it can `fail`   NITPICK-TYPE-042 "`drop` is licensed only by a `never fails` callee (D-163)"
```

So F-4's `drop layout_push(@l, FmtPart.Year4);` and `drop layout_lit(@l, "-");` compile only if both are `never
fails`.

### 1.5 The pool, and a string's length

`int64` → `uint16` by `=>!` truncates in silence — 65 543 becomes 7 — and the checked `=>` is refused,
`NITPICK-TYPE-009` (TM-105). `string_length(s)` is `NITPICK-RESOLVE-002`; `string_bytes(s).len` is the length, 4 for
`"ab-c"` and 0 for `""`. So a literal's length is read without reading a byte, and every narrowing §4 makes has its
range check written beside it: the length's is `layout_lit`'s own `if`, and the offset's is the bound PD-151 states.

```nitpick
// write: src/fmt/fmt.npk
// Formatting and parsing -- cycle 0.4.0: the layout type (`FORMAT_MODEL.md`
// §3, F-4 and F-7).
//
// WHAT IS HERE: `FmtPart`, the thirty parts of a layout; `Layout`, a value
// holding them and its own text pool; `layout_new`, `layout_push`,
// `layout_lit`, `layout_validate` and `layout_free`. The formatter and the
// parser that read a layout are cycle 0.4.1's and 0.4.2's.
//
// WHAT IT MAY IMPORT: `zone`, `span`, `cal` and `core` (`BUILD.md` B-17) --
// `core` alone today.
//
// CONSTRUCTION NEVER FAILS, AND A STEP A LAYOUT CANNOT TAKE IS RECORDED: F-4's
// own example calls `layout_push` and `layout_lit` by `drop`, which only a
// `never fails` callee licenses (the compiler's D-163). A `Literal` pushed by
// hand, a part past `NTIME_PARSE_MAX`, and an empty literal or one longer
// than `NTIME_PARSE_MAX` bytes append nothing and set `refused`, and
// `layout_validate` answers false for that layout ever after.
//
// THE POOL: `Literal(off)` holds the BYTE OFFSET of its entry in `pool` -- one
// length byte, 1 ... `NTIME_PARSE_MAX`, then the literal's bytes. A layout
// holds at most `NTIME_PARSE_MAX` parts and each literal at most
// `NTIME_PARSE_MAX` bytes, so the pool never passes 128 x 129 = 16 512 bytes:
// every offset fits `uint16` and every length `uint8`, and that bound is the
// two narrowings' range check (`SAFETY.md` S-15b).
//
// WHAT WILL NEVER EXIST HERE: a format string. No `strftime`, no
// `layout_from_pattern` (TM-009, TM-023) -- a layout is a TYPED VALUE.
// `check_no_format_string` holds every text parameter in `src/` to a copy or
// its length.
mod:fmt;

use "../core/vec.npk".Vec;
use "../core/vec.npk".vec_init;
use "../core/vec.npk".vec_push;
use "../core/vec.npk".vec_at;
use "../core/vec.npk".vec_free;
use "../core/bytes.npk".Bytes;
use "../core/bytes.npk".bytes_init;
use "../core/bytes.npk".bytes_push;
use "../core/bytes.npk".bytes_extend_str;
use "../core/bytes.npk".bytes_len;
use "../core/limits.npk".NTIME_PARSE_MAX;

pub enum:FmtPart = {
    Literal(uint16);        // the byte offset of its entry in the layout's own text pool
    Year4; YearExpanded; YearShort2;
    Month2; MonthName; MonthAbbr;
    Day2; DaySpace2;
    Hour24_2; Hour12_2; AmPm;
    Minute2; Second2;
    Nanos3; Nanos6; Nanos9; NanosAuto;
    WeekdayName; WeekdayAbbr; WeekdayIsoNum;
    DayOfYear3; IsoWeekYear4; IsoWeek2;
    OffsetColon; OffsetCompact; OffsetOrZ;
    ZoneAbbr; ZoneName;
    UnixSecs;
};
impl:FmtPart:Copy = { };

pub struct:Layout = { hidden Vec<FmtPart>:parts; hidden Bytes:pool; hidden bool:refused; };

pub func:layout_new = Layout() never fails {
    pass Layout{ parts: raw vec_init::<FmtPart>(8i64), pool: raw bytes_init(16i64), refused: false };
};

pub func:layout_push = NIL(Layout->:l, FmtPart:p) never fails {
    if (l.parts.count >= NTIME_PARSE_MAX) {
        l.refused = true;
        pass NIL;
    }
    bool:is_lit = false;
    pick (p) {
        (FmtPart.Literal(off)) { is_lit = true; },
        (*)                    { }
    }
    if (is_lit) {
        l.refused = true;
        pass NIL;
    }
    drop vec_push(@l.parts, p);
    pass NIL;
};

pub func:layout_lit = NIL(Layout->:l, string:src) never fails {
    int64:n = string_bytes(src).len;
    if (n < 1i64 || n > NTIME_PARSE_MAX || l.parts.count >= NTIME_PARSE_MAX) {
        l.refused = true;
        pass NIL;
    }
    int64:off = raw bytes_len(@l.pool);
    drop bytes_push(@l.pool, n =>! uint8);
    drop bytes_extend_str(@l.pool, src);
    drop vec_push(@l.parts, FmtPart.Literal(off =>! uint16));
    pass NIL;
};

pub func:layout_validate = bool(Layout:l) never fails {
    if (l.refused) { pass false; }
    bool:after_wide = false;
    int64:i = 0i64;
    while (i < l.parts.count) decreases l.parts.count - i {
        FmtPart:p = raw vec_at(l.parts, i);
        bool:wide = false;
        bool:auto = false;
        pick (p) {
            (FmtPart.NanosAuto)    { auto = true; },
            (FmtPart.YearExpanded) { wide = true; },
            (FmtPart.UnixSecs)     { wide = true; },
            (*)                    { }
        }
        if (auto) { pass false; }
        if (wide && after_wide) { pass false; }
        after_wide = wide;
        i = i + 1i64;
    }
    pass true;
};

pub func:layout_free = NIL(Layout->:l) never fails {
    drop vec_free(@l.parts);
    pass NIL;
};
```

## 6. What will bite

- **A bare call of a `NIL` function is `NITPICK-TYPE-039`, and `drop` of a fallible one `NITPICK-TYPE-042`** —
  `drop layout_push(@l, …);`, always (§1.3).
- **`string_length` resolves to nothing** at the pin: `string_bytes(s).len` (§1.5).
- **A `Layout` is moved or lent, never copied, and always released**: `layout_free(@l)` before the scope ends, or
  the program exits 96 (§1.4). Inside `fmt`, a lent layout's parts are `vec_at(l.parts, i)` — `@l.parts` of a lent
  `Layout` is `NITPICK-TYPE-085`.
- **A `pick` arm's variant is qualified** — `(FmtPart.Year4)`, never `(Year4)` (`probe05`'s first lesson).
- **`=>!` truncates in silence** (TM-105): every narrowing in §4.1 has its range check beside it — `layout_lit`'s
  `if` for the length, PD-151's bound for the offset — and a change to either bound is a change to both narrowings.
- **The three plants of `layout_lit`'s pool are invisible to 0.4.0's tests** (§1.6): the pool is read first by
  0.4.1's formatter, whose goldens are where a wrong offset or length shows.
- **`check_no_format_string` reads uses, so a text parameter bound to a second name is a finding** (§4.4): copy or
  measure it where it is named.
